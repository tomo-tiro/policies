# policies

公開アプリのプライバシーポリシー兼サポートページを集約する公開リポジトリ。

GitHub Pages で `https://tomo-tiro.github.io/policies/` に公開される。

## 構成

```
policies/
├── index.html        # アプリ一覧トップ
├── te-ssera/
│   └── index.html    # te-ssera のポリシー・サポート
└── <アプリ名>/
    └── index.html    # 新規アプリはサブフォルダを追加
```

## 公開URL

- 一覧: `https://tomo-tiro.github.io/policies/`
- te-ssera: `https://tomo-tiro.github.io/policies/te-ssera/`

## アプリ追加手順

1. `<アプリ名>/index.html` を追加
2. ルート `index.html` の一覧にカードを追記
3. push すれば自動で反映される
