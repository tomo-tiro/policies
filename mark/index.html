プライバシーポリシー・サポート　制定日 2026年11月5日

集めている情報

mark は、あなたの個人情報を収集しません。アカウント登録もありません。

撮影した表紙・背表紙・ページの写真、ページから読み取った文字、引いたマーカー、書いた言葉、日記、読書の記録、本棚の内容は、すべてあなたの iPhone の中だけに保存されます。開発者や第三者のサーバーに送られることはありません。

外部サービスとの通信

本の情報（書名・著者・判型・表紙画像など）を調べるため、次のサービスに ISBN または入力した検索語だけを送り、表紙の画像を受け取ります。

  • openBD（株式会社カーリル・版元ドットコム）
  • 国立国会図書館サーチ・書影API（国立国会図書館）
  • Google Books API（Google LLC）
  • 楽天ブックス書籍検索API（楽天グループ株式会社）※利用する場合

また、アプリの更新を確認するため、起動時に Expo（650 Industries, Inc.）の配信サーバーへ接続します。送るのはアプリの版の情報だけです。

いずれの通信でも、インターネットの仕組み上、あなたの端末の IP アドレスや OS・アプリの種類などが相手のサーバーに届きます。各サービスでの情報の扱いは、それぞれのプライバシーポリシーに従います。

カメラと写真

カメラは、本のバーコード・表紙・背表紙・ページ・読んだ場所と、共有する画像の背景を撮るためだけに使います。写真ライブラリへのアクセスは、写真から選ぶときと、作った画像を保存するときだけです。ページの文字の読み取りは iPhone の中で行い、外部には送りません。

共有

共有の操作をしたときだけ、あなたが選んだアプリへ画像と文章を渡します。共有できるのは、本の表紙・帯・あなたが書いた言葉・読書の記録で、撮ったページの写真は共有しません。

解析・広告

利用状況の解析ツールや広告は使っていません。

データの削除

本棚のゴミ箱で本ごとに削除できます。アプリを削除すると、端末内のすべてのデータが消えます。

お問い合わせで受け取る情報

お問い合わせの内容は、そのお返事と不具合の調査のためだけに使い、ほかの目的には使いません。お問い合わせ先の GitHub の Issue は誰でも見られる場所です。お名前・メールアドレスなどの個人情報は書かないでください。

改定

内容を変えるときは、このページでお知らせします。

サポート・お問い合わせ

不具合のご報告やご要望は、次の GitHub リポジトリの Issue にてお願いいたします。
